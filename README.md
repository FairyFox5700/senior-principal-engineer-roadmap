# Senior → Principal Engineer Roadmap

A sourced, project-led 12-month roadmap covering engineering fundamentals, continuous delivery, architecture, reliability, security, business judgment, communication, influence, mentoring, cross-team leadership, strategy, Azure, and agentic systems.

## Files

- [`senior-principal-engineer-roadmap.pdf`](./senior-principal-engineer-roadmap.pdf) — polished 20-page PDF
- [`ROADMAP.md`](./ROADMAP.md) — editable Markdown source
- [`roadmap.html`](./roadmap.html) — print-ready HTML source
- [`sources-ledger.json`](./sources-ledger.json) — citation URL ledger

## Approach

- 70% applied work
- 20% feedback and mentoring
- 10% study
- One observable artifact and completion criterion per phase
- Section-level references from GitHub, Google, DORA, Microsoft, NIST, OWASP, GitLab, Dropbox, and Backstage

## Regenerate the PDF

On Windows with Google Chrome installed:

```bash
"C:/Program Files/Google/Chrome/Application/chrome.exe" \
  --headless --disable-gpu --no-pdf-header-footer \
  --print-to-pdf="senior-principal-engineer-roadmap.pdf" \
  "file:///ABSOLUTE/PATH/TO/roadmap.html"
```

The roadmap is guidance, not a universal leveling standard. Map its evidence expectations to your employer’s official career framework and promotion process.
